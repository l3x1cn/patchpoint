## Notes on the exit codes above

# - Blocks whose command ends in `grep -c …`/`grep -vc …` or `grep -n …` show the exit code of that last grep: 1 means "no line matched" (count 0), which is the expected outcome for the negative contract checks (`grep -vc '@sha256:'`, `grep -vcE '@[0-9a-f]{40} # v'`, the empty `.trivyignore`, `schedule:`, `sbom|syft|cosign|attest`, `kics|checkov`, `gitleaks|trufflehog`, `fail2ban|sshguard|crowdsec`, and `ip6 saddr` in example.conf).
# - `git check-ignore -q docs/testing/reports/x.md` exits 1 = the path is NOT ignored (the expected result).
# - Blocks that end in `| wc -l`, `| jq …` or `| tail` show the exit code of that last command; the `gh run view … --log | grep` block runs under `set -o pipefail`.
